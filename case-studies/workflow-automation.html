Case Study · Automation

Every form response, actionable in minutes.

A Zapier pipeline that removed manual email-sending entirely from a vendor registration workflow.

Client
Vendor Registration Program
Tools
Zapier, Google Forms, Gmail
Role
Workflow Automation Build
Result
0 manual emails

The problem

A client was manually processing vendor registration form responses and sending follow-up emails one by one — a task that ate hours every week and delayed every new vendor's onboarding.

What I built

I built a Google Form for structured data capture at the front end, then automated the response-routing and follow-up emails using Zapier, so every submission triggered its own next step without anyone touching it.

Zap trigger and action chain — a new form response routes straight into a personalized follow-up.

This same pipeline structure now powers Mimi, an AI lead-scoring chatbot I built that drafts personalized replies straight to Gmail.

Result

Outcome

Removed manual email sending entirely, making every form response actionable within minutes of submission.
